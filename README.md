# 4tak-website

En moderne, responsiv nettside utviklet for 4Tak AS, et firma som tilbyr taktekking og relaterte tjenester.

Nettsiden er utviklet med fokus på brukervennlighet, tilgjengelighet, ytelse og et ryddig design som fungerer på både mobil og desktop.

🚀 Teknologier

Astro – Komponentbasert struktur og generering av statiske HTML-sider

HTML5 – Semantisk og tilgjengelig struktur

CSS3 – Responsivt design med mobile-first tilnærming

JavaScript – Interaktiv mobilnavigasjon

Git & GitHub – Versjonskontroll

✨ Funksjonalitet

Responsivt design tilpasset ulike skjermstørrelser

Gjenbrukbare komponenter for header og footer

Felles layout for tjenestesider

Mobilmeny med animert hamburgerikon

Aktiv side-markering i navigasjonen

Klikkbare brødsmulestier (breadcrumbs)

Kontaktinformasjon med klikkbart telefonnummer

Egen presentasjon av firmaets tjenester

🎯 Prosjektets mål

Målet er å gi 4Tak AS en profesjonell digital tilstedeværelse der potensielle kunder enkelt kan finne informasjon om firmaets tjenester og komme i kontakt.

Prosjektet er bygget med fokus på enkel videreutvikling og vedlikehold.
